# Fábio Teraoka — site profissional

Landing page pessoal em Next.js, com identidade visual escura, linguagem editorial e foco em engenharia, aviação e gestão.

## Executar localmente

```bash
npm install
npm run dev
```

Abra http://localhost:3000.

## Publicação

Projeto preparado para deploy na Vercel. Importe este repositório e mantenha o comando de build padrão (`npm run build`).

## Antes de divulgar

Revise e confirme cargos, períodos, escopo das experiências, indicadores e links de contato. Os números com asterisco são pontos de validação editorial. Substitua os links genéricos do LinkedIn e o endereço de e-mail pelo contato público correto.
